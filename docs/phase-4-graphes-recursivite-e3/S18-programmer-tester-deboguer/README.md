# S18 – Algorithmique appliquée : écrire, tester et déboguer

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 1re année – mathématiques pour l'informatique |
| **Séance** | S18 (séance 18 sur 19) – Phase 4 |
| **Durée** | 4 heures |
| **Chapitre du programme** | Algorithmique appliquée – écrire un programme, le tester, corriger les erreurs |
| **Prérequis** | S03, S04, S12 (conditions, boucles, fonctions, tableaux) ; S15 (validation de données). |
| **Outils** | Papier, calculatrice, éditeur Python intégré au site |

> [!NOTE]
> **Question qui guide la séance :** *« Face à un énoncé de l'épreuve, comment passer de la question à un programme correct, et comment savoir qu'il est correct ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Reformuler** un énoncé : entrées, sortie, exemple à la main ;
2. **Écrire** un algorithme en pseudo-code puis en Python (accumulation, recherche avec arrêt anticipé, comptage, série consécutive) ;
3. **Choisir** des jeux de tests avec des cas limites ;
4. **Dérouler** un algorithme par un suivi de variables ;
5. **Repérer** et **corriger** des erreurs classiques (indices hors domaine, mauvaise initialisation, arrêt trop tôt, division entière, effet de bord).
