> [!NOTE]
> **Question qui guide la séance :** *« Comment gérer deux heures d'épreuve, rédiger des réponses justifiées et vérifier ses résultats ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Connaître** le format de l'épreuve E3 et la manière de gérer son temps ;
2. **Rédiger** une réponse complète : méthode, calcul, résultat, vérification ;
3. **Identifier** ses points faibles par un auto-diagnostic ;
4. **Composer** sans aide un sujet de 2 h et **se corriger** avec le barème ;
5. **Écrire** un algorithme en Python sur un sujet type.
