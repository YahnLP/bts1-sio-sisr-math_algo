# Outils

## Python dans le navigateur

Les TP Python s'exécutent **directement dans la page**, sans installation : un éditeur, un bouton pour lancer le programme et un bouton pour **vérifier** avec les tests de la séance. L'interpréteur est **Pyodide** (Python 3.10 compilé pour le navigateur). Il se charge à la première ouverture d'un TP ; une connexion à Internet est donc nécessaire.

Règles utiles :

- le programme est stocké **dans ton navigateur** : pense à copier ton code avant de vider les données du site ;
- les tests donnent un message en cas d'erreur ; relis-le avant de modifier ;
- tu peux aussi travailler dans un éditeur installé sur ton poste (Thonny, IDLE, VS Code) : le code des exercices est du Python standard.

## Les formules

Les formules sont affichées avec **MathJax**, chargé depuis un réseau de diffusion (CDN). Clic droit sur une formule : « Copier en LaTeX » ou agrandir.

## Calculatrice

Pour l'épreuve, la calculatrice autorisée dépend de la réglementation de l'année : **vérifie la circulaire en vigueur**. Entraîne-toi à utiliser les fonctions utiles : fractions, puissances, reste d'une division, matrices si ton modèle les propose.

## Papier et crayon

Tracer une table de vérité, dérouler un algorithme ligne par ligne (**trace**), dessiner un graphe : ces gestes se font à la main et se préparent mieux qu'ils ne se devinent. Chaque séance les demande.
