| **Prérequis** | S09 (ensembles). |
| **Outils** | Papier, calculatrice, éditeur Python intégré au site |

> [!NOTE]
> **Question qui guide la séance :** *« Comment relier deux ensembles, et quand une correspondance est-elle fiable pour coder, trier ou regrouper ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Définir** le produit cartésien et **calculer** son cardinal ;
2. **Étudier** une relation binaire (réflexive, symétrique, antisymétrique, transitive) ;
3. **Reconnaître** une relation d'équivalence et **décrire** ses classes ; **reconnaître** une relation d'ordre ;
4. **Distinguer** application, injection, surjection, bijection, et **composer** des applications ;
5. **Déterminer** une image directe et une image réciproque.

## Application en informatique

Regroupement des adresses d'un même sous-réseau (équivalence), ordre des tâches ou des versions (ordre), codage d'informations (injection), tri (image réciproque), correspondance adresse IP → adresse MAC.
