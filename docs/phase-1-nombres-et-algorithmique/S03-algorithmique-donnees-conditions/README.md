> [!NOTE]
> **Question qui guide la séance :** *« Comment décrire une solution en pseudo-code, puis la traduire en Python sans changer son sens ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Écrire** l'en-tête d'un algorithme (nom, rôle, entrées, sortie, variables typées) ;
2. **Choisir** le type d'une donnée : entier, réel, booléen, chaîne ;
3. **Écrire** des expressions avec les opérateurs numériques, de comparaison, booléens et **bit à bit** (masque, mise à 1, mise à 0, changement d'état) ;
4. **Écrire** une structure conditionnelle (si… alors… sinon) en pseudo-code indenté et en Python ;
5. **Dérouler** un algorithme à la main sur un jeu d'essai (trace) et **tester** un programme.
