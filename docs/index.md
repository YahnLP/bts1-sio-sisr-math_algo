## Comment lire les cours

Un survol d'un sigle (PGCD, CIDR, MPM…) affiche une infobulle ; le [glossaire](ressources/glossaire.md) les réunit tous. Les réponses des exercices sont **repliées** : cherche d'abord, déplie ensuite. Les corrigés complets sont dans chaque séance et le [formulaire](ressources/formulaire.md) rassemble toutes les formules.
