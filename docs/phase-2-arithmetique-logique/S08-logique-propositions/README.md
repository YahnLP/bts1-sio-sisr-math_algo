> [!NOTE]
> **Question qui guide la séance :** *« Comment dire sans ambiguïté qu'une condition est vraie, et comment savoir que deux conditions écrites différemment sont équivalentes ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Reconnaître** une proposition et lui **attribuer** une valeur de vérité ;
2. **Construire** la table de vérité d'une expression avec ¬, ∧, ∨, ⇒, ⇔ (et ⊕, « ou exclusif ») ;
3. **Identifier** une tautologie, une contradiction, deux expressions équivalentes ;
4. **Écrire** la négation, la réciproque et la contraposée d'une implication ;
5. **Traduire** une règle de filtrage ou une condition de boucle en expression logique.
